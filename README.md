# Rucoy-Fishing-Mastery
Fishing game made for browser completely free using A.i
What's new:

✅ Auto-saves every 30 seconds while playing
✅ Saves instantly when you catch a fish, buy items, or travel maps
✅ Continue button appears on the start screen when a save is found
✅ Shows your name, level, gold and fish count on the saved game screen
✅ 💾 Saved! indicator pops up bottom-right when it saves
✅ Delete Save button if you want to start fresh
